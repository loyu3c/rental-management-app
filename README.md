# 包租代管 App

以 Android 手機管理不動產、租約與收租，逐步加入押金、修繕、房貸、資金流水及 Google 試算表報表。

## 專案狀態

0.30.0-preview 是整合測試版，已實作手機本地不動產／單位／租約建檔、分層導覽、搜尋篩選、帳單、租金與水電合併開單、每月電表與水電計算、合併匯款分配、部分繳款、收租狀態篩選、繳費明細複製、即時明細更新、千位逗號、帳戶期初、舊收款對應、支出分攤、房貸扣款、共用現金、銀行互轉、對帳、每租約押金收付、部分退款、固定左側欄位名稱、退租分項結算、押金抵付、分次補繳、退租後換新租客、抄電表拍照／相簿選照、帳單讀數帶入、語音轉文字與支出／收款／轉帳草稿、目前租客姓名及姓名搜尋，並支援v8完整ZIP備份。GitHub Actions 使用固定簽署金鑰產出 APK。

Google 房東月報手動同步已實作，但需在自己的帳號完成服務部署與設定，尚未實際啟用；背景自動同步及租客分檔權限未啟用。語音以手機服務轉文字，再依常見句型整理可修改草稿，不是雲端AI解析。電表照片可從租約明細拍攝／選取並存手機。退租結算需人工核對費用，不自動退款。確認後暫不提供取消結算或更正補繳。尚未完成實機更新及操作驗收，請先使用測試資料。

## 原則

App 為帳務來源；Google 試算表規劃為唯讀報表。帳務、照片與備份不提交到 GitHub；簽署密鑰保存於 GitHub Secrets，不寫入程式或 APK。
