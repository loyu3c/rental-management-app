# 退租換約與獨立停車出租

2026-10-03，補充 requirements.md 與 mobile-design.md。

## 使用者確認

停車出租獨立於房客：獨立承租人、租約、帳單與收款，不作為房屋租約附加項目。固定格位或不指定位置尚未確認，不能假設一人一格。

## 出租單位

出租單位支援房間、整棟、停車與其他空間。停車租約無需关联住宅租約。停車的房東/管理歸屬、收款帳戶、金額、繳款週期、租期與押金依實際建檔，不猜數值；水電不默認啟用。

固定車格按獨立單位與租期檢查重疊；若出租不指定位置的資格，另以容量模型處理，確認前不套用固定車格限制。車牌等欄位非已確認必填需求。

停車租金與住宅租金分類統計，總收入只加總一次。停車承租人如使用報表，採獨立租約報表及其Gmail授權；尚未確認所有停車承租人是否具備Gmail。

## 退租與換租客

- 舊租客資料與已確認租約不得直接改名為新租客。
- 記錄實際交還日期；有代收電費則記最後讀數與照片。
- 結算欠租、水電、預收款、押金扣抵及退款；非整月租金由管理者確認，不預設比例。
- 空間交還與帳款結清分开：可標空置/待整理，而舊租約保持待結算，繼續追欠款。
- 新租客建立新租約、新押金與起租電表基準。租期不能與占用相同空間的租約重疊。
- 舊讀數與新基準間空置期用電不得算入新租客。
- 押金扣抵與退款須有明細；扣抵不虛構銀行入帳，退款只扣實際資金一次。
- 新租約產生新的Google報表，不能重用有舊租客資料的檔案；舊報表保留歷史，管理者可選擇撤除舊租客權限。

## 驗收

1. 同房間舊租約結束、新租約開始後，舊欠款與押金均不轉移到新租客。
2. 舊租約仍欠款不妨礙已交還空間建立不重疊的新租約。
3. 新租客報表不包含舊租客資料。
4. 停車承租人不需要房屋租約，即可建立獨立帳單與收款。
5. 停車收入單列且納入總收入，避免重複計算。
