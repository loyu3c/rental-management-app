# APK 整合測試版

版本 0.6.1-preview，versionCode=8，applicationId=com.loyu3c.rental.preview。固定簽署沿用既有 GitHub Secrets。

## 下載與安裝

登入有權限的 GitHub 帳戶，進入 Actions 的 **Android Fixed Signature APK** 成功執行紀錄，下載 **rental-management-fixed-signature** ZIP，解壓縮後安裝 app-release.apk。Debug Checks 只做檢查，不提供安裝檔。

從同一固定簽署版本更新可使用 Android 覆蓋安裝流程；實際保留資料升級仍待使用者驗證。舊 debug 簽署版若提示簽署不符，請先匯出完整備份，不能直接承諾跨簽署覆蓋；不要在未備份時移除已存資料的版本。

## 一次測試的流程

1. 先在報表匯出完整備份，再安裝；第一次測試請用測試資料。
2. 不動產清單選一棟 → 搜尋／篩選／排序單位 → 單位明細與租約，確認不再整頁堆操作按鈕。
3. 先到記帳建立各銀行及一個共用現金帳戶，填起算日與當日開始前餘額。再選一個測試租約，使用「建立當月帳單」，同頁確認租金、水費和電表，再一次建立（先在租約填月水費與電價）。首末月需手動填實際租金，不自動按天折算。
4. 例如租金10000、水250、電表100→160、電價5，登錄10300合併匯款，預覽後確認，應剩水電250未付。
5. 另建年繳測試租約，開12張每月租金單，登錄一筆全年匯款，核對僅一筆實際收款。
6. 報表匯出 v3 備份，確認建檔、帳單、收款、帳戶、支出、轉帳及對帳均包含。還原會替換全部資料；舊 v1 備份沒有帳務紀錄，還原後帳務清空；v2還原會清空帳戶、支出、轉帳與對帳。

Google、拍照、語音、押金收付與退租結算尚未啟用。帳單已收款後不能直接撤銷；錯誤收款可撤銷原登錄及分配，但不能當作實際退款。

建置：JDK17、Gradle8.9、AGP8.7.3、compileSdk35。固定簽署流程執行 :app:testReleaseUnitTest :app:assembleRelease :app:lintRelease。CI 成功不代表已完成實機驗證。

0.5.1 的年繳入口保留獨立按鈕；已開立的月份沿用原帳單，完整月份不再新增。已付金額依實際收款分配判定。規格與驗收結果見 [合併每月帳單](changes/unified-monthly-bill.md)。

## 支出與零用金測試

- 舊收款需先逐筆對應到實際帳戶，不自動猜測；可勾選顯示已對應紀錄更正帳戶。
- A、B、C銀行各提款10000到共用現金，銀行各減10000、現金增30000，支出保持不變。
- 現金修繕3000分攤A1000、B2000，總支出3000，現金只減一次。
- 房貸選房貸扣款類別，只填實際整筆扣款及對應分攤，不拆本金利息。
- 到帳戶流水輸入存摺實際餘額，保存差額核對；不自動補調整交易。
- 起算日前歷史可補登報表，不再次改變期初餘額。期初填錯可在流水修正並記原因，修正會重算帳面，請先備份。

[本批規格與驗收](changes/expenses-cashflow.md)。仍以測試資料驗證手機操作，尚未登錄不表示沒有交易，押金收付尚未實作會影響實際餘額對帳。

## 日期與收到租金

租約明細點「＋ 收到租金」後，點日期欄位開啟日曆，選日期再確認。月帳單／年繳／支出報表的月份以年、月選擇器選取；其他付款、提款、帳戶起算與對帳日期亦使用日曆。不更動舊交易資料或分配。
