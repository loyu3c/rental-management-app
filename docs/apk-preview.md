## 一次測試的流程

1. 先在報表匯出完整備份，再安裝；第一次測試請用測試資料。
2. 不動產清單選一棟 → 搜尋／篩選／排序單位 → 單位明細與租約，確認不再整頁堆操作按鈕。
3. 先到記帳建立各銀行及一個共用現金帳戶，填起算日與當日開始前餘額。再選一個測試租約，使用「建立當月帳單」，同頁確認租金、水費和電表，再一次建立（先在租約填月水費與電價）。首末月需手動填實際租金，不自動按天折算。
4. 例如租金10000、水250、電表100→160、電價5，登錄10300合併匯款，預覽後確認，應剩水電250未付。
5. 水電算好再建立完整月帳單，登錄收到租金後，同一帳單視窗應立刻更新已付與未付，不需要關閉重開。
6. 報表匯出 v6 完整ZIP備份，確認建檔、帳單、收款、帳戶、支出、轉帳、對帳、押金收付、退租結算、抄表及照片均包含。還原會替換全部資料；舊 v1 備份沒有帳務紀錄，還原後帳務清空；v2還原會清空帳戶、支出、轉帳與對帳。

Google尚未啟用；退租結算需人工核對，不自動退款。帳單已收款後不能直接撤銷；錯誤收款可撤銷原登錄及分配，但不能當作實際退款。

建置：JDK17、Gradle8.9、AGP8.7.3、compileSdk35。固定簽署流程執行 :app:testReleaseUnitTest :app:assembleRelease :app:lintRelease。CI 成功不代表已完成實機驗證。

## 支出與零用金測試

- 舊收款需先逐筆對應到實際帳戶，不自動猜測；可勾選顯示已對應紀錄更正帳戶。
- A、B、C銀行各提款10000到共用現金，銀行各減10000、現金增30000，支出保持不變。
- 現金修繕3000分攤A1000、B2000，總支出3000，現金只減一次。
- 房貸選房貸扣款類別，只填實際整筆扣款及對應分攤，不拆本金利息。
- 到帳戶流水輸入存摺實際餘額，保存差額核對；不自動補調整交易。
- 起算日前歷史可補登報表，不再次改變期初餘額。期初填錯可在流水修正並記原因，修正會重算帳面，請先備份。

[本批規格與驗收](changes/expenses-cashflow.md)。仍以測試資料驗證手機操作，尚未登錄不表示沒有交易，押金需補登實際收付後再核對帳戶餘額。

## 0.9 退租一次測試

1. 先匯出v5備份。租約→帳單與收款→退租／結算費用。
2. 退租日期點日曆。最後租金手填；已開最後月份沿用，未開水電需填讀數與水費。向租客收修繕／其他費用另外填；支付師傅的費用仍在記帳登錄。
3. 例如押金20000、未付租金5000、水電1200、修繕3000：費用9200，抵付9200，待退10800。確認結算不動銀行餘額；另外登錄實際退款10800才扣銀行。
4. 費用高於押金時，用收到結算補繳分次登錄；同筆資金只計一次。總覽可查看待收／待退，結算明細可複製。
5. 同一單位下一位租客另建新租約，起租日須在原退租日翌日或之後。原租約到期日及歷史保留，帳務分開。
6. 未分配預收租金、退租後帳單或收款會擋下結算，先核對。預收租金退款尚未實作。
7. 結算確認後原帳務鎖定；本版尚無撤回結算或更正補繳，請先用測試資料。匯入v1–v4舊備份會替換並清空結算，先保留v5備份。

1. 報表先匯出完整ZIP備份。覆蓋安裝本版後，不動產單位卡片確認顯示目前租客姓名，搜尋可用姓名；到期或未起租不當作現在租客。

3. 例「今天A棟修繕總共三千元，從共用現金付款」。核對文字，再整理、帶表單，確認單棟分攤及現金付款正確。

## 0.15.0 房東每月合併報表

報表 → 爸爸的每月總報表／CSV匯出，選月份查看所有不動產、各棟與租約明細。租金水電依收到日期合併實收；帳單應收依月份，抵付及持有押金截至月底。結算實際補繳另列，非現金抵付不重複算收款。支出按各棟分攤，撤銷不列入；淨收款不含押金與轉帳，也不是銀行餘額或會計損益。

CSV含總計、不動產、租約列，按列別區分，不可整份重複加總。只含姓名房號帳務，不含電話Gmail備註照片。自行匯入Google試算表，非自動同步；租客獨立報表／雲端權限仍未啟用。
