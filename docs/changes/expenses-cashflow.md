# 0.6.0：支出、房貸與共用零用金

## 規格與範圍

依已確認需求，整合銀行帳戶、共用現金、支出分攤、房貸整筆扣款、提款／轉帳、存摺對帳及半年歷史補登。App本地資料為來源；此版尚不連接Google或銀行，也不加入押金收付、退租結算、照片、語音。

- 每個資金帳戶以獨立ID保存名稱、銀行／現金類型、起算日、起算日開始前餘額；共用現金僅一個。銀行可指定主要不動產供收款預選，實際收款時仍需核對選擇。
- 新收款必須選實際帳戶，年繳按一筆實際收款計入銀行，與帳單分配無關。舊收款不猜帳戶；提供搜尋與逐筆手動對應／更正入口，不新增收款或修改帳單分配。
- 支出類別為修繕、電梯保養、房貸扣款、其他費用；選銀行或現金、日期、項目、付款總額，各不動產手動填金額。分攤總和必須等於付款總額，付款只扣一次。
- 房貸僅記每月實際總扣款，不拆本金、利息。月報為現金支出報表，不當成正式會計損益。
- 提款是銀行→共用現金的轉帳，銀行間轉帳同樣只移動資金；不增加收入或費用。手續費另記支出。
- 帳戶餘額=期初+起算日及之後實際收款-支出+轉入-轉出；查詢日期之後資料不計入。起算日前歴史仍供報表及流水查看，不重複影響期初。
- 存摺／點算現金對帳保存日期、實際餘額、當時帳面快照與備註，顯示差額但不強行調整資金；後續補登時另顯示依目前資料重算的帳面。
- 期初填錯可在帳戶流水修正日期與餘額，需原因、保存之前期初設定並重算帳面；不能當成日常補帳。新起算日不可晚於已有對帳日期。
- 支出、轉帳可撤銷錯誤，保留原紀錄、原因與撤銷日期，重新計算餘額與報表；不得代替實際退款。收款沿用原撤銷流程，尚非完整正式稽核系統。
- 帳面允許呈現負數，但不表示自動借款；未齊帳務、未對應舊收款與未實作押金收付會影響真實對帳，畫面明示。
- 保存採預覽後確認及UUID重複確認檢查；相同日期／帳戶／金額／項目的支出或轉帳會阻止重複，實際另一筆需填不同交易辨識。

## 資料與升級

新增accounts、expenses、transfers、reconciliations；receipts增加accountId，原帳戶文字保留。舊資料保留、不自動遷移帳戶關聯。備份v3包含全部九類資料，先驗證金額、分攤、ID與關聯後原子還原；v1還原清空帳務，v2還原清空帳戶、支出、轉帳與對帳，確認提示明示。銀行帳號與憑證不要求填入、不提交GitHub。

applicationId與固定簽署不變，versionCode=7。測試資料與手機覆蓋升級仍需實機驗證。
