# 0.33.0-preview

- New/unbilled lease terms opt into monthly, quarterly, half-yearly and annual rent periods. Price can instead be daily or a fixed whole-stay price with one-time payment. Short-stay day counts include both dates; monthly groups are calendar-month based, anchored to the starting month, with first/final partial months prorated by actual days and one rounding at period total. First due date advances by the period length. Utilities continue monthly with manually confirmed actual charges.
- The same rent invoice is reused throughout its covered months; utilities remain independent monthly invoices. Home tasks show due dates and suggested period rent. No push notification is sent.
- Posted legacy leases retain their prior monthly ledger behavior. Posted new terms cannot change dates/pricing/periods; renewal requires a separate nonoverlapping lease. Early termination of prepaid periods requires manual review; prepaid rent refunds remain unsupported and are blocked rather than silently overcharged.
- Rental units support enabled/disabled status; only enabled units count as occupied/vacant. Building mode atomically toggles the whole-building unit versus rooms/other spaces, retaining parking and land settings. Current/future leases block disabling. Historical records are retained. Existing units default enabled; choose the intended mode once after updating if both whole and room units already exist.
- Lease creation/editing offers save-and-attach initial meter photo, with camera/gallery, thumbnail, replacement, deferred removal, and initial-reading locks independent of photo attachment. Cancellation leaves the saved lease intact. Activity request codes 51/52 are distinct. Pending photo state survives activity recreation and guards concurrent lease edits.
- Full ZIP backup schema 11 includes initial meter photos, with validation and fresh file names on restore. Legacy backups remain readable. Older app versions cannot import schema 11.
- Added tests for rent period calculations, partial months, inclusive day counts, duplicate rent prevention, independent monthly utilities, legacy behavior, rental mode counts and atomic conflicts, and initial photo archive integrity.
