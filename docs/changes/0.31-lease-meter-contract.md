# 0.31 租約起始電度與PDF合約

租約新增可留空的起始電度欄位。零為有效值，非負整數上限10億。起租月份無既有抄表／上期帳單時帶入，後續月份不反覆套用；已有起始值及帳單／抄表時鎖定。舊租約可補登，既有帳單不更動。

租約表單提供儲存後選取PDF按鈕，租約卡片可上傳、更換及開啟PDF。透過系統檔案選擇器讀取，複製至App私有目錄，限25MB以下、可由PdfRenderer開啟且未加密的PDF。取消選取不改合約，失敗不覆寫原參照。待選租約ID跨Activity重建保存。與每個租約獨立關聯，退租仍可查看。

完整ZIP增加contracts項目並保留合約名稱、起始電度。版本9可讀舊v1–v8；有合約的JSON-only備份拒絕還原。附件驗證後才替換現有資料。還原重建合約檔名並保留關聯。Google同步未增加PDF雲端上傳。
