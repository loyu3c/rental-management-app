# 0.29 租約預設與延長

新增租約選起租日後到期日帶入一年後同日，可再手動改。起租日再次更改則重新帶入；2月29日加一年按日曆落在2月28日。新增預設管理者代收水電、固定月水費200、電價5；編輯原租約保留原值，不用預設覆蓋。

已有帳單／收款／押金租約開放到期日延長，不能縮短。起租日、租金、應繳日、押金與週期維持鎖定；提交再驗證，過期畫面拒絕覆寫。原帳單與流水不改，後續開單與到期提醒依新到期日；原對帳快照保留。與其他房間／整棟租約的日期重疊仍拒絕。

此延長僅適用同一租客且原租金／押金條件不變。租金／押金調整另需規劃，不可直接改有帳務的原租約。已退租仍鎖定，換租客另開租約。這是App資料維護，不會產生或簽署新的租賃文件。

驗收：新增預設、起租日選擇／重選、手動改到期日、閏年；原租約水電不被預設覆寫；有帳務延長、不縮短、不改歷史金額；重疊與已退租阻擋。
