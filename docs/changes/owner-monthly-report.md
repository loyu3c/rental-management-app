# 0.15 房東合併月報與CSV

手機報表頁提供真正的房東每月總覽、各不動產分攤支出與租約帳務明細。租金水電按收到日期合併實收；當月帳單按月份列應收、截至月底抵付及未付，非現金押金抵付與結算分配影響帳單狀態但不再列租金實收。結算實際補繳另列一次。銀行提款／轉帳及押金收退款不列入此淨收款。押金持有列截至月底。當月未建帳單明確標示，不推定已繳清。

CSV是UTF8 BOM、標準引號逃逸與公式文字保護，包含總計、各不動產及租約列；使用列別分辨層級，不可把全部列加總。只含姓名房號及帳務欄，沒有電話、Gmail、照片、帳號或備註。姓名等文字以=+@-開頭會加單引號保護。由使用者選擇本機或雲端文件位置，自行匯入試算表；非自動同步、非租客權限功能。不能將含所有租客的房東CSV分享給租客。

驗收：9月預收算10月帳單抵付但不算10月實收；11月收到的欠款不回填10月底抵付；押金抵付只算帳單清償；結算補繳現金只列一次；撤銷修繕不列支出；分攤A1000 B2000總支出3000；未建帳單單位顯示未建；CSV姓名逗號引號可匯入且不含聯絡欄位。CI含4個報表測試，Android文件匯出及Sheets匯入待實機確認。
