# 0.36.1-preview：第二層圖示與按鈕間距

使用者實機回報：第二層頁籤需要圖示，記帳頁新增、語音、篩選按鈕相接過近，語音圖示與文字分離。

## 實作

- 收租、記帳、不動產、報表的第二層頁籤採上方 18dp 線條小圖示、下方短文字；維持選取樣式、無障礙名稱及至少 56dp 觸控高度。圖示列與標籤整組置中。
- 同一頁籤列各項左右保留 2dp，整列下方 10dp。
- 共用列表標題／新增列下方留 8dp；語音操作與篩選之間留 8dp，篩選下方 6dp。維持緊湊排版，避免按鈕邊框相接。
- 語音記帳採共用置中圖示動作元件，圖示 20dp、與文字間隔 8dp，不再將圖示放在整個按鈕最左邊。
- 只調整呈現；頁籤歸屬、帳務計算、資料與分享權限不變。

## 驗收

- [x] 各主要頁籤均對應圖示且保留文字，不只靠圖示或顏色判讀。
- [x] 靜態檢查共用標題／語音／篩選間距；新增 vector XML 可解析。
- [x] Android 單元測試、lint、固定簽署 APK。
- [ ] 手機實際確認小圖示、大字體換行及間距。

Given 記帳頁，When 查看新增支出、語音與篩選，Then 按鈕不相接、語音圖示與文字整組置中。

Given 任一第二層頁籤，When 切換或返回，Then 原有選擇與功能不變，圖示及標籤可一起點擊。
