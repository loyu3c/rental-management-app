# 語音轉文字與帳務草稿

版本0.11.0-preview / versionCode13，包含出租單位卡片目前租客姓名與姓名搜尋。

依第三種方案：語音轉文字，再整理成帳務草稿，由管理者確認存檔。支援支出／房貸扣款、收到租金、提款／轉帳。使用手機既有RecognizerIntent繁中服務，不內嵌API金鑰；語音服務可能使用網路。App用保守的本地規則整理常見句型，不是雲端AI自由語意解析。

記帳→語音記帳／文字草稿：說話→選正確文字→修改文字→整理草稿→確認種類／租約→帶入原有表單→補日期、帳戶與分攤→預覽→確認保存。缺資料留空或請選，不擅自用當天或第一帳戶。明說今天／昨天／前天可帶相對日期，完整年月日可識別。中文正式整數金額及阿拉伯數字加元／塊可識別；模糊三千五、一萬二、負數、小數不猜或四捨五入。

帳戶與不動產名稱使用App代稱精確匹配。同名、多帳戶、多房號或歷史租約不唯一時需自行補選。已退租租約改用專用結算入口。多棟分攤不平均；只有明說單棟、明確總額時可帶單棟全額，仍需核對。總額與分攤不一致由既有驗證拒絕。押金、退款、退租或混在提款中的手續費先擋下，提醒專用入口或拆成兩筆。

草稿與文字不直接寫入帳務；原語音文字帶入備註，可修改；本版不保存錄音，不新增帳務資料格式。沒有系統語音服務時可鍵盤語音或手填文字。取消不新增交易，重複保存由既有流程攔截。

測試：中／阿拉伯金額、模糊金額、單棟支出、租客房號、電話不能當房號、明確轉帳方向、多棟分攤、資料缺漏、押金／退款／手續費限制、小數／負數、重複房號與退租、相對及完整日期、千位逗號。實際手機辨識與表單操作待驗證。
