# 0.37.0-preview：第三批搜尋與附件統一

## 功能與位置

- 出租單位、收租應收、收款查詢、支出／轉帳採共用搜尋篩選元件：上方搜尋與篩選、右側重設、下方目前條件。
- 條件預設收合，展開狀態於本次使用階段保留；查詢欄位與原本篩選邏輯不變。
- 重設回各頁預設：出租單位為啟用出租與代號升冪；應收為全部租約；收款為本月及全部收付類型；支出／轉帳為全部月份與全部有效／撤銷紀錄。
- 搜尋或重設只更新畫面，不增刪或重算保存帳務。
- 支出編輯照片使用 64dp 縮圖、文字及右側更多選單；查看與移除分開，不再以叉號遮住圖片。移除先改草稿，確認保存才生效。
- 起始電表照片重用同一列式元件，更多內可查看、更換、移除；無照片仍可新增。PDF 保留文件圖示、長檔名與更多選單，與租約一起保存。
- 支出照片查閱改為共用全頁返回，含歷史版本的照片仍讀各版本快照。抄表紀錄照片直接顯示縮圖入口，撤銷仍在紀錄更多並需確認。
- 保留 0.36.2 的輸入法與預覽計算修正，不改共用編輯視窗生命週期。

## 邊界與後續

本批統一已有搜尋能力的核心列表；報表月份選擇、帳戶對帳日期等專用查詢保留原領域名稱。支出單張照片的更換沿用移除後新增，不新增無追蹤的照片覆寫。
