# 0.32 支出照片憑證

## 行為
新增／修改支出在項目下加入照片區，每筆最多3張，拍照或選相簿，顯示縮圖與移除。選取外部照片前保存完整表單草稿及原版本，返回後重建表單，取消選取不改已保存紀錄。新檔存在App私有目錄，單張25MB以下並驗證可解碼。取消表單清除本次新增檔，儲存才建立支出參照。移除只解除新版本參照，歷史照片不刪除。照片不改金額或分攤。

列表金額／分類右側80dp首張縮圖靠右，顯示照片張數，點擊看全部縮圖並可開原圖。無照片不留右側空間，分攤明細保持靠左。撤銷保留照片；修改紀錄可查看當時附件。

ZIP版本10新增expenses附件，備份包含目前與歷史照片，檔名及3張限制檢查，JSON-only有附件拒絕還原，還原先驗證照片、移至新檔名並重寫全部歷史參照。舊v1–v9相容。本版只存手機，雲端照片尚未實作。
