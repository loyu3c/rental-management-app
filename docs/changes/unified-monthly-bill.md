# 0.5.1：合併每月租金與水電操作

## 問題與規格

使用者不理解「單月租金」和「當月水電與電表」為何要選兩次。確認改為單一「建立當月帳單」，租金、水費、電費、合計、已付與尚需繳付同頁顯示。年繳租金保留另一入口。

- 月份、租金、固定月水費及電表讀數同頁輸入，金額自動帶入租約。水費可調整當月實際金額，不修改租約或舊帳單。讀數完整後即顯示合計，確認前不保存。
- 自行繳水電租約隱藏水費與電表，只建立租金。
- 年繳已開租金單會沿用，不再開一次；已付狀態依真正收款分配，不能只因租約寫年繳或已開單就說已預繳。已付年租的月份新增水電後僅需繳水電差額。
- 已有租金或水電的月份沿用該筆 ID 與金額，欄位唯讀；僅補齊欠缺項目。完整月份再次進入顯示總額、不再次開單。
- 首末月租金不自動按天比例計算，需填實際應收。水費未知或電表缺少／倒退不能確認合併帳單，不將未知視為零。
- 年繳入口只開租金，最多12個月、到租約結束停止，跳過已有月份並明列新增月份與合計。不因開立帳單新增收款。
- 租約帳單明細依月份合併成卡片，尚未建立的水電顯示待建立，不能用0代替。撤銷按原項目處理，已有分配的項目仍不可撤銷。

## 資料與相容

只合併操作與呈現；底層租金／水電兩類紀錄沿用 v2 備份資料模型，不合併或改寫歷史 ID、電價快照、分配。一次確認以一筆 SharedPreferences commit 保存新增項目，避免只成功一半。舊備份及收款分配仍相容。applicationId與固定簽署不變，versionCode=6。
