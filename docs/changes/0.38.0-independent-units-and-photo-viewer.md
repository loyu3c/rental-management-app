# 0.38.0-preview：獨立出租單位與 App 內照片查看

## 規格與範圍

依 2026-10-17 使用者決定，不動產 → 物件 → 出租單位預設及重設為「全部（含停用）」。其他頁篩選保留原領域預設。

不動產更多選單移除整棟／分房切換；刪除批次切換及類型互斥邏輯。新增單位預設啟用，可建立倉庫、雨遮等其他空間並逐一開關。類型只描述單位，不推斷重疊範圍；出租狀態、租約重疊與備份檢查一律以同一單位 ID 為準，整棟租約不再覆蓋其他單位。既有啟用／停用值不變，不自動啟用舊資料；仍禁止直接停用有有效／未來租約的單位。

照片共用入口改為 App 內全頁檢視，提供返回、雙指縮放、拖曳、雙點還原／放大。支出及歷史、起始電表、抄表紀錄使用同一查看方法；返回保留來源表單／列表，不寫資料。圖片解碼長邊限制 2048 像素以控制記憶體，原始附件與備份檔不變；PDF 維持原開啟方式。

## 任務與驗收

- [x] 出租單位預設及重設全部（含停用）。
- [x] 移除切換 UI、批次切換函式與新增／啟用時的類型互斥。
- [x] 共用 App 內圖片檢視與原頁返回。
- [x] 獨立開關、其他單位不變、租約保護與來源不變的單元測試。
- [x] 模擬器加入 App 內圖片開啟／返回測試，保留五項輸入與搜尋測試。
- [ ] Release／Debug 建置、lint、帳務／同步測試及六項模擬器測試。
- [ ] 實機雙指縮放、長圖、旋轉、歷史照片與大字體回歸。

Given 有停用單位，When 首次進入或重設篩選，Then 包含該單位，統計仍只計啟用單位。

Given 同一不動產有整棟、房間、倉庫、車位，When 個別啟用其中之一，Then 其他單位保持原狀。

Given 單位有目前或未來租約，When 停用，Then 顯示先處理租約提示，不改資料。

Given 點照片縮圖，When 顯示大圖並返回，Then 不出現外部應用選單且來源及附件資料保持原狀。

## 邊界

不改帳單、租金、歷史、分享及 Google 同步。物理空間是否重疊由管理者配置，不自動推斷；未啟用單位不列空房，仍可由全部列表查閱。自動化不代表已完成實機手勢、相機與 PDF 驗收。
