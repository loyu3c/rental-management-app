# 0.35.0-preview：第一批 UI 架構統一

## 範圍與歸屬

依據 [UI 與功能架構規範](../ui-architecture-guidelines.md)。本批處理租約詳情、單筆選單、全頁表單與返回來源，不變更資料格式或帳務計算，也不更動 Google 服務或授權。

- 不動產的租約卡片、收租與相關總覽進入同一租約詳情：概況／帳務／押金與結算／附件。
- 租約右上角更多：修改租約、租客報表與分享；是否可修改依既有業務狀態決定。
- 帳務頁保留建立帳單與抄表入口；押金收退和退租結算放同一頁籤。
- 合約與起始電表照片集中在附件頁，以縮圖／文件、名稱與狀態、操作圖示呈現；更換或移除進既有租約草稿編輯，儲存後生效。已退租租約保留原本直接補附／更換 PDF 的能力，不開放修改已鎖定租約。
- 支出、轉帳、押金、抄表、帳戶流水及管理卡片使用共用右上角更多選單；僅顯示該類資料原本支援的操作。
- 帳單與結算來源展開仍保留直接按鈕，靠左且顯示展開狀態。
- 新增／修改不動產、單位、名稱、類別、房東、帳戶及收租／押金／轉帳／結算／對帳等表單使用共用全頁框架，固定底部取消與儲存或核對。金流原有核對確認仍保留。
- 租約與支出現有全頁草稿加入一致返回箭頭及放棄變更提示；照片、PDF 選取繼續保留原草稿流程。
- 詳情與查詢頁左上角返回實際來源，不再固定寫返回不動產。主要列表捲動、物件搜尋／排序／篩選在本次使用階段保留。
- 共用小圖示使用同一線條 vector，觸控區至少 48dp，撤銷等選單文字使用紅色。

## 驗收案例

| Given | When | Then |
|---|---|---|
| 不動產的租約或收租列表 | 點同一租約 | 開同一個四頁籤詳情；返回回原列表 |
| 已有帳單或已退租租約 | 開更多操作 | 不繞過原本鎖定與退租限制 |
| 支出、轉帳、押金、抄表等紀錄 | 點右上角更多 | 只顯示支援的操作；撤銷要再核對確認 |
| 帳單或結算來源 | 點明細 | 直接展開或收合，不必先進更多選單 |
| 已修改的輸入或租約附件 | 取消或系統返回 | 提醒放棄；繼續編輯保留內容，放棄不入帳 |
| 收款、支出、轉帳、押金等表單 | 點核對 | 不直接入帳；原確認與防重複邏輯保留 |
| 租約編輯已有附件 | 取消選檔、移除後取消表單 | 舊附件不因取消而被替換或移除 |
| 長租客名、長 PDF 名稱、大字體 | 開詳情或表單 | 內容可換行，操作區不遮欄位，鍵盤開啟可捲動 |

## 驗證紀錄與限制

- 本地 Node Google 同步契約與分享隔離測試通過；本批未修改服務端或傳輸協定。
- 第一輪 Debug 建置／lint、Release 單元測試／lint 與固定簽署 APK 均通過：Actions 38969556977、38969556799。最後一輪保留舊租約 PDF 與退款入口修整將再次建置；交付以最後成功 APK 為準。尚未實機驗證。
- 五大入口第二層頁籤、設定集中、所有頁面的新增與搜尋入口整理屬第二批，尚未完成。
- 語音草稿與部分簡短確認仍使用彈窗；支出照片維持既有縮圖列，後續再統一完整附件介面。
- 列表狀態保留以同一 Activity 使用階段為範圍；尚未全面處理各詳情頁在程序重建後的還原。租約附件既有草稿恢復機制保留。
