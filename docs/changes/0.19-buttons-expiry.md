# 0.19 按鈕層次與到期提醒

保留暖色與租約四分頁。主要收款／開單用深棕實心按鈕；次要操作用圓角細框，均有按壓回饋、至少48dp高度且可隨文字換行。四分頁使用圓角選取背景；去除租約畫面的重複左右內距與預設灰色返回按鈕。押金撤銷放入對應紀錄內，僅餘額大於零才顯示退還押金。金額依原千位格式顯示。

首頁新增租約到期提醒，按日期由早到晚顯示所有已到期但未退租，以及未來60天內到期（含當日與第60天）的租約。已退租排除，不限定出租單位種類。點租約開啟原帳務。只讀清單，不改資料、不自動退租、不發送外部通知。

驗收：到期邊界、已退租排除、排序與來源不變的單元測試；既有帳務單元測試、Release編譯、lint、Google同步契約測試。手機實際排版、大字體及更新資料保留待安裝驗證。
