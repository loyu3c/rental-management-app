# 0.30 出租狀態燈與合計

單位卡片綠燈出租中、灰燈未出租，保留租客姓名。未出租仍可顯示待起租／租約已到期子狀態。清單新增未出租篩選。

不動產總表显示全部合計與每棟的出租中／未出租；單棟上方也有總數。總數依全部已建檔單位，不隨搜尋篩選改變。未建立出租單位的物件顯示0/0；待起租／到期歸未出租。綠／灰另配文字避免單靠顏色。

依台北今天及有效租約（含既有退租日期端點）讀取，不更動帳務。整棟租約涵蓋同棟房間與其他空間，獨立車格與土地依其自己的租約；數量以已建檔單位逐筆計算，不是租約筆數。

驗收：混合出租／未建約／待起租／到期／退租／換租客／整棟與独立車格、跨物件合計、空物件；顏色文字、篩選、點卡片與保存後刷新實機確認。
