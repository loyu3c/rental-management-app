# 0.20 統一介面與待辦總覽

首頁、收租、記帳、不動產、報表共用暖色主題與圓角按鈕。主要操作使用深棕色，次要操作細框；可操作卡片、快捷及底部導覽加入按壓回饋。群組展開與搜尋篩選會顯示展開／收合狀態，原生表單與日曆使用暖色主題。閱讀面板改為一致的整頁捲動內容及關閉按鈕。報表操作分類為帳務報表、資料備份與同步。

待辦總覽從首頁／報表進入，可依逾期待收、未完成開單、待抄電表、結算待收、押金待退篩選。逾期為應繳日期早於今日且仍欠款；本月已起租且租約涵蓋本月時追蹤缺租金／代收水電帳單。自行繳水電不要求抄表。已有水電帳單或有效當月抄表不再提醒抄表。未來起租不提醒當月開單。已結算租約只追蹤尚待補繳與持有押金退款，避免與原欠款重複。同租約可有多種待辦。點選對應開單、抄表或租約帳務，保存後刷新清單。只讀計算，不自動產生交易，不發外部通知。

驗收：到期日邊界、繳清消失、自繳水電、未來起租、撤銷抄表、已出水電帳單、退租結算排除重複及資料不變測試；既有Android單元測試、Release編譯、lint、Google同步契約測試。手機大字體、日曆、資料保留與各頁互動待實機驗證。
