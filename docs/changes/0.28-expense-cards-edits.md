# 0.28 支出卡片與修改紀錄

## 確認規格

支出卡片第一行項目＋金額，日期、分類、付款帳戶固定名稱；分攤倒三角預設收合。修改直接可見，更多選單放撤銷與查看修改紀錄。已撤銷灰色刪除線且不可修改。

修改帶入日期、項目、分類、帳戶、金額、分攤，預覽確認後同一ID更新；保留修改前快照及時間。快照不参与餘額／統計，只有最新有效版本計數。撤銷保留資料、排除統計；實際退款仍另記帳。修改重算帳面，原對帳快照不改。既有停用分類可保留。防止過期畫面覆蓋新版本。

同樣支出卡片套用近期紀錄與支出報表明細。轉帳保持原功能，不新增轉帳修改。搜尋仍包含收合的分攤內容。

## 備份

完整備份v8，包含支出內的歷史快照。舊v1–v7可還原；新v8需使用0.28或更新版，避免舊版還原後遺失修改紀錄。歷史需有效格式、分攤合計及存在的關聯。

## 驗收

修改帳戶、日期、金額，確認舊帳戶與月份移除、最新餘額／分攤／報表只計一次；第二次修改、撤銷後保留全部歷史；過期／已撤銷修改拒絕；備份還原歷史可查。窄螢幕、長項目、分攤展開、更多選單及即時刷新需手機操作驗證。
