# 0.40.0：一般收入與設定頁版本

## 範圍
- 設定頁從 Android PackageInfo 讀取實際版本與建置編號。
- 記帳的支出頁改為收支；新增收支選收入或支出，共用原支出流程。
- 一般收入提供入帳日、收款帳戶、利息收入／其他收入、金額與說明；不要求不動產或租約。
- 全頁收入表單底部取消／核對，預覽後確認入帳。卡片更多提供修改、歷史、撤銷；撤銷保留原因與時間並收合。
- 收入只增加所選帳戶一次；起算日前補登及未來交易不影響查詢日餘額，撤銷不計，修改只計最新版。
- 收支列表篩選合計與管理總覽的收支報表獨立顯示一般收入；帳戶流水、房東共享報表的帳戶餘額包含收入。租客報表不含一般收入。一般收入不分攤至房屋，房東物件租金淨收款仍依原定義。
- 備份升至 v14 加入 incomes，還原 v1–v13 時初始化空收入集合；舊版不接受 v14，避免遺失收入。
