# 固定左側欄位名稱

依使用者回饋，填入內容後提示文字消失，無法辨識姓名、租金、應繳日、押金及電價。所有文字／數字／日期輸入改為左側固定名稱、右側內容，類型與水電方式等選單亦加名稱。長說明保留於輸入提示或原有說明，日期選擇、數字格式及存檔規則保持不變。

v3資料與固定簽署不變。此版未實作押金實收，租約「約定押金」不是收款紀錄；不得使用租金入口代替押金收取。押金收付列為下一個業務功能，需獨立流水與租約餘額，並接銀行／現金及備份。
