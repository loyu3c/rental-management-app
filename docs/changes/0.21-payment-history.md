# 0.21 收款紀錄查詢

收租頁新增統一收付查詢，依實際交易月份（預設本月／可選全部月份）、收款類型、姓名／單位／帳戶／備註／金額搜尋。類型區分租金水電、收到押金、退還押金、結算補繳。依日期由新到舊顯示，20筆一批；合計以全部符合條件的紀錄計算。點紀錄可開啟原租約帳務，保存後查詢即時刷新並保留條件。

僅統計實際金流：租金現金收款、有效押金收退、結算payments。cash:false的結算抵付／合成收款及押金抵付費用排除，避免重複計數；撤銷押金排除。交易淨流入=租金水電實收+收到押金+補繳−押金退款，不代表收入或帳戶餘額，不包含支出與轉帳。無帳戶對應的舊收款仍顯示原帳戶說明，需自行核對。查詢只讀，不改資料格式與分配規則。

驗收：非現金／撤銷排除、補繳不重複計數、各類與淨流入、日期排序、月份／類型／搜尋與合計一致、來源資料不變；既有Android測試、Release編譯、lint、Google同步契約測試。實機操作與覆蓋更新待驗證。
