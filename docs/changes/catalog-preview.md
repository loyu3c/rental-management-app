# 0.2.0 建檔試用版

## 範圍與狀態

已加入暖色底與棕色文字、五個入口，不動產入口改名。現階段為暖色方向的原生介面，尚未完整還原互動設計稿的所有排版。

已實作本機新增及查看建築物/土地、不動產下的出租單位。單位類型含房間、整棟、車格、土地出租範圍、其他空間；代號可填C1、R1401。

不動產名稱去除首尾空白後不能重複；同一不動產內代號不區分大小寫重複檢查，不同不動產可同代號。內部UUID與顯示代號分離。SharedPreferences保存目錄資料，儲存失敗不顯示成功。

此階段未啟用租约、帳務、修改/刪除、資料備份、拍照、語音或Google同步。請使用測試資料。沒有正式簽署金鑰，debug版本可能不能覆蓋前版；移除App會刪除本機資料。

## 驗收與檢查

- [x] 程式差異檢查：新增非空限制、代號歸屬、取消不新增、保存成功後重載。
- [ ] 實機新增A棟與土地，建立R1401/C1並重啟確認保存。
- [ ] 實機同物件重複代號被拒，不同物件可同代號。
- [ ] 實機檢查鍵盤、長名稱、返回與畫面旋轉。
- CI編譯與lint結果以對應GitHub Actions成功紀錄為準；不等同已實機驗收。
