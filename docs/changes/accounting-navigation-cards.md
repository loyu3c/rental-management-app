# 0.12 記帳分類與卡片操作

底部分頁使用不同向量圖示，收租為錢幣符號，保留原文字與頁面功能。記帳頂部三個快捷：記支出、語音記帳、提款／轉帳；帳戶管理收合新增帳戶、流水對帳、舊收款對應；更多功能收合押金與退租。支出分攤報表原本已在報表頁，保留此入口。無帳戶時仍顯示新增帳戶入口。

記帳近期紀錄及支出報表的撤銷按鈕位於卡片內右下方，最小48dp觸控高度。沿用原撤銷原因與確認流程，不刪除紀錄。已撤銷卡片只顯示狀態。歷史顯示與帳務計算不變。

驗收：五分頁圖示不同且文字保留；小螢幕三快捷不遮住底部分頁；兩群可展開收合並開啟各原功能；撤銷指定支出與轉帳只影響該笔並即時更新；無帳戶仍能建帳戶。手機外觀、大字模式及覆蓋安裝資料保留待實機驗證。預覽圖的月份搜尋不是本批已實作功能。
