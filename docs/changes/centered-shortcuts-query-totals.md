# 0.14 快捷置中與查詢摘要

上方三快捷改用垂直LinearLayout內含26dp圖示與獨立文字，以整組CENTER對齊，上下12dp內距及6dp外距一致；最小高度92dp，可隨字體增加。功能沿用原入口。

記帳查詢結果顯示有效支出與轉帳總額，按所有符合月份、類型、搜尋文字的紀錄統計，不受15筆載入限制。已撤銷兩種類型均不列總額，轉帳不加到支出，合計使用long。此為查詢支出總額，不是單棟分攤總额或帳戶餘額。

驗收：手機三快捷圖示與文字整組上下置中；大字模式及三快捷可點。修繕3000、銀行提款10000、撤銷500應顯示有效支出3000、轉帳10000；載入更多不改總額；月份及文字篩選會重算。包含單元測試及既有CI；手機外觀待確認。
