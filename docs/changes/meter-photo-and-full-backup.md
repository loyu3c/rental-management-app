# 抄電表照片與完整備份

0.10.0-preview / versionCode 12。新增每租約每月份抄表紀錄，含抄表日期、前後讀數、備註及可選照片。可透過系統相機或文件／相簿選擇器附照，先預覽確認再保存。讀數需手填，不做OCR。照片只存手機，不會上傳GitHub或Google。原圖以圖片程式檢視，可點預覽開原圖。

新增帳單帶入同一租約、同月份最新有效讀數；跨租客不沿用，已開帳單沿用既有讀數及金額。錯誤抄表可撤銷但不刪照片或改帳單。單位明細→帳單與收款→抄電表／查看照片。

備份格式v6，匯出為完整ZIP：catalog.json加photos/附件。純讀數也可不附照。匯入舊v1–v5 JSON保留相容，這些版本不含抄表照片；還原確認說明替換全部資料。含照片的v6不能只用JSON還原。ZIP拒絕路徑穿越、未知項目、重複、缺照／未關聯照片與大檔；單張25MB、總量300MB、最多2999張。先於隔離目錄讀取、驗證，再將照片改為全新檔名以免覆寫舊資料，最後原子替換帳務。取消及驗證失敗不替換資料，未引用舊照片留在手機，不自動刪除。

使用系統相機content URI及單一檔案暫時權限，不要求整個相簿存取。選取圖片也複製至App內，來源刪除不影響保存照片。pending草稿保存以便相機回傳及程序重建；相機取消不新增紀錄。匯出／讀取／還原大型照片在背景執行，UI顯示進度。

驗收：讀數依租約／月份篩選、撤銷不沿用、租期與倒退讀數阻擋、單位關聯、ZIP照片原位元組往返、缺照／錯誤路徑／未知項目拒絕、缺照不能匯出、舊JSON及純讀數備份。相機、相簿及圖片程式需實機驗證。語音與Google同步未啟用。

帳單保存 meterReadingId 作為抄表依據，與原讀數保持一致；撤銷抄表不移除已開帳單的歷史連結。
