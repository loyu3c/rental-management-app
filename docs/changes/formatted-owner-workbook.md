# 0.16 千位逗點與房東Excel報表

新增xlsx匯出，保留CSV原始資料。金額使用真正數字儲存及#,##0顯示格式，負數為數字；房號姓名為inline文字，不當公式執行，前導零保留。報表分為總覽、各不動產、租約明細，凍結首列表頭，明細有篩選及設定欄寬，暖色表頭。沿用OwnerReport計算，沒有變動帳務。

使用者在Android選擇保存位置，快照存於App私有設定以支援程序重啟，匯出以背景執行。Google試算表自行開啟或匯入，不是自動同步；檔案含所有租客姓名，供房東查看，不是租客個別報表。

測試：ZIP內容及XML可解析、9760儲存數字並套格式、負數數字、三工作表及凍結篩選、001房號保留文字、姓名含公式符號與XML控制字元安全。實際Android匯出及Google試算表開啟外觀待實機確認；不同試算表讀取器可能呈現不同欄寬或顏色。總計與明細是不同層級，不可跨表重複加總。
