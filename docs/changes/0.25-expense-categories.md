# 0.25 可編輯支出類別

記帳→更多功能→支出類別管理，新增、改名、停用／啟用；不可空白、重名或超過40字。預設修繕顯示修繕費用，增加清潔打掃。類別固定id關聯既有expense.category，改名只改顯示，支出與分攤不重寫。停用不再出現在新增選單，歷史支出／合計仍保留。已使用類別不刪除，避免孤立關聯。類別管理用於分類與統計，項目備註記錄具體內容。

所有支出顯示、流水及按類報表使用當前名稱。語音既有修繕／電梯／房貸關鍵字保留，加上清潔打掃及啟用自訂名稱完整比對；辨識多類時要求手選，停用類別不自動帶入。語音仍須預覽確認。

完整備份升為v7，包含expenseCategories。v1–v6還原補預設類別，v7保留自訂id、名稱與啟用狀態；新備份需用此版本或更新版本還原。

驗收：改名／停用保留支出key、重名／遺失關聯拒絕、類別備份往返與舊預設，以及既有Android測試、Release編譯、lint、Google契約測試。實機新增清潔類別、修改修繕、歷史合計、語音、停用與備份還原待驗證。
