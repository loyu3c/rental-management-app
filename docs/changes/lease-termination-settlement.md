# 退租結算與換新租客

版本 0.9.0-preview，versionCode 11。

需求：押金與費用分開；最後租金自行填寫；費用超過押金可另補繳。結算沿用原租金／水電帳單，未開的最後月份一次補齊；修繕及其他費用另外列項。向租客收修繕費與付給師傅的支出分開。

確認時原子保存租約退租日期、最後帳單、結算快照、押金抵付、帳單抵付。押金抵付不動銀行資金，不列實際匯款。退款仍依實際日期、帳戶、金額另登；超額費用可分次補繳，每筆資金只計一次。補繳先清原帳單，再清修繕／其他。確認後歷史帳務鎖定，只能退款與補繳，暫無撤回結算或更正補繳功能；預覽畫面明確提醒先備份。尚未分配的預收租金及退租後帳單／收款需先處理，預收租金退款尚未支援，不推測或丟失金額。

租約保留原到期日，另存 terminatedOn 作為實際租期結束。同一房號新租約需從退租日翌日開始；沿用同房號但新建租約與押金。整棟、房間、獨立車格／土地一律同規則。原租客欠費不妨礙翌日新租約，仍保留待收與待退。

備份格式 v5 包含 settlements；一般升級不清資料；匯入舊v1–v4不含結算，確認告知會替換。結算資料驗證參照、金額、原帳單與分配快照、押金來源、補繳及抵付關聯。禁止無結算來源的非現金收款／押金抵付。

驗收：20000押金、5000租金、1200水電、3000修繕，抵付9200且銀行不扣，退款10800後銀行剩9200。費用超過押金分次補繳銀行只增加一次；原帳單不重複；歷史期初不重複；自行繳水電；預收款／未來帳單阻擋；重複結算／過量或過早補繳阻擋；快照破壞阻擋；備份往返與截止日計算。
