# 0.13 分頁排版與記帳查找

底部分頁改為獨立ImageView及TextView垂直置中，圖示固定22dp，內距8dp，最小64dp並可隨字體增高，避免Button複合圖示的上緣及字距問題。五個分頁功能不變。

記帳近期紀錄可依全部／指定月份、有效支出／有效轉帳／已撤銷篩選；搜尋日期、項目、帳戶、不動產及金額文字。每次15筆，可載入更多。儲存與撤銷後保留目前篩選；不改原帳務資料。預設全部月份，以免補登舊資料被隱藏。

驗收：手機底部图示完整，文字與圖示間距穩定；大字模式仍完整。月份日曆選擇、類型、關鍵字組合篩選及載入更多；撤銷指定紀錄後有效支出篩選中消失，已撤銷可查到。CI編譯與既有帳務測試，外觀需實機確認。
