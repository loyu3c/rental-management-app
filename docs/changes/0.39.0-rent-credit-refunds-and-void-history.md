# 0.39.0-preview：未分配收款、實際退款與撤銷歷史

依 2026-11-12 使用者確認，從 main `340e78b9517c958b5dbc3775185b0697e064193f`（0.38.0）開發。versionCode 53，備份格式 13。

## 功能與位置

- 租約概況、帳務、押金／結算及退租表單都可進同一「未分配收款／退款」全頁，返回保留來源及退租欄位。
- 每筆原收款列日期、帳戶、已抵付、已退款、未分配餘額；展開抵付去向。
- 單筆右側更多可選同租約待繳帳單及金額抵付；只改分配，不新增銀行收入，保留原分配快照。
- 預收租金退款填實際日期、實際付款帳戶、金額及原因，核對後點「確認已退款」才保存；不代替銀行轉帳。
- 退款不能早於收款、超過未分配餘額、跨房東已知帳戶或重複確認。部分退款後仍可分配剩款。
- 退款隸屬原收款，扣實際付款帳戶一次，不列修繕等支出；收付款查詢、帳戶流水、首頁與房東／租客報表一併反映。
- 押金沿用獨立收退及結算抵付；結算仍先核對費用、押金扣抵、待退押金、待補繳，實際收退另登錄。
- 支出、轉帳、押金、抄表與退款的已撤銷卡片共用預設收合，可展開原內容、照片及原因。
- 帳單／收款撤銷改為原子移入 voidRecords，保存原快照、原因、時間；可從租約帳務及押金／結算查閱。
- 無關聯帳務的誤建租約可從右上更多作廢，原租約及附件留在歷史；有關聯帳務先處理，不偽造退租。有分享時必須已確認撤除才可作廢。

## 資料規則

餘款＝原實收－抵付－有效退款。退款的撤銷只用於錯誤登錄，必填原因並保留原紀錄；已結算來源含退款快照鎖定。確認頁以整份帳務快照比對，資料變更時拒絕過期提交。

備份版本升至 13，避免舊版忽略退款而算錯餘額；舊備份升級時補空撤銷歷史。作廢租約照片／PDF 納入完整 ZIP，還原時同樣重命名引用。

## 邊界與待交付

本版處理「尚未分配」收款退款；已抵付且帳單涵蓋退租日以後的款項，仍需另規劃帳單調整／退租後期間退款，不自動改寫已收帳單。原本不支援撤銷的結算補繳與整筆結算沒有新增撤銷能力。

舊版已實體移除的錯誤帳單／收款無法憑空重建歷史；新版本之後撤銷才會保存原快照。

GitHub 已重新連接；完整建置與操作驗證已通過，APK 使用既有固定簽章。
