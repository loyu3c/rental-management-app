# 0.41.4：收租及帳戶列表統一精簡

範圍：收租→應收帳務／收款紀錄、記帳→帳戶。這三頁的大卡片與固定說明占用首屏，改用共用精簡列及資訊圖示。

- 應收：房號與租客、物件、租期三行，右側為未開單／待繳金額／已繳清；原待繳與篩選算法不動，點列開原租約詳情。
- 收款：保留原月份／類型／搜尋條件、20筆載入與全篩選合計，摘要改為筆數與淨流入；各項分類及會計口徑點資訊查看。日期／類型與金額首行，單位／租客／帳戶次行。點列看完整備註並可前往原租約帳務；明細更新時重讀有效交易狀態。
- 帳戶：名稱與原計算餘額首行，起算／期初次行，點列到原流水與對帳；未起算另標示。說明以資訊圖示開啟。
- 收租頁籤圖示與文字並排，重複同步狀態不占首屏。應收未篩選時隱藏重設與重複全部條件，收款保留月份提示，非預設條件才顯示重設。
- 無列表更多及重複箭頭，左右12dp留白，兩行56dp／三行64dp最小高度，可隨字體增長。長文字省略，數字完整顯示。返回保留原條件與位置。
- 只調整呈現與查看路徑，不修改帳務、備份v14、歷史、同步或分享規則。套件與簽章沿用，版本碼59。

- [ ] 模擬器：三頁首屏至少6筆可見，點列查看、返回、分類與餘額核對，帳務不變及截圖。
