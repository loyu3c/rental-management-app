# 0.22 上期電表與語音欄位連動

Google設定暫停，保留既有程式但不部署或同步資料。

新增抄表依選取月份帶入同一租約上一個月份的本期讀數。已存在水電帳單優先，其次最新有效抄表紀錄，排除撤銷紀錄。同月資料、未來月份、其他租約及跳過月份不帶入；缺紀錄手填。切換月份重新帶入上期，清空本期避免誤留上月輸入；來源顯示在表單，數字仍可手改。開立月帳單若已有本月水電／抄表優先沿用，否則也帶入上一個月份本期。已建立帳單不修改。

語音草稿類型與可見內容連動。支出／房貸：支出分類、付款帳戶、分攤，隱藏租約與轉帳資訊。收到租金：收款帳戶及房號／租客選擇，隱藏支出分攤與轉出入。轉帳：顯示轉出轉入，隱藏租約與分攤。待選類型只顯示共通資料。切換立即更新核對提示，收租才驗證租客，仍需下一頁預覽確認才保存。

驗收：同租約上一月份、無跨租客／無跳月、撤銷排除、既有帳單優先、跨年度及不修改來源的測試；既有Android單元測試、Release編譯、lint與同步契約測試。手機月份切換、手動修正、語音類型反覆切換仍待實機驗證。
