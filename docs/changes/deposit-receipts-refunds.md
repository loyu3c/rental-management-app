# 押金收付與固定欄位名稱

版本：0.8.0-preview / versionCode 10。

每份租約分開記錄約定押金、實際收到、退還及持有／待退餘額。收付需選日期與實際銀行或現金帳戶，確認預覽後保存。押金進出影響資金流水，與租金收入及支出報表分開。支援部分退款、補登歷史與有原因的錯誤撤銷，不支援扣抵租金或修繕、自動退租結算。

退款依日期核對每份租約已收押金，不能使用未來收款或其他租約押金。同日先收後退。已退款的收款不能直接撤銷，須先處理錯誤退款。起算日前押金計入持有餘額，不重複加減帳戶期初資金。

所有表單欄位保留左側名稱。新增或撤銷後開啟中的租約、總覽及帳戶頁自動更新。

備份格式 v4 包含 deposits。支援匯入 v1–v3，但這些舊備份不含押金收付，還原確認會說明清空押金紀錄。一般更新 APK 保留資料，不推算約定押金為實收。

驗收：部分退款、帳戶與押金餘額、歷史起算、跨租約限制、退款日期、撤銷依賴、同日順序、無效帳戶與金額。GitHub CI 執行單元測試、release build、lint；手機互動待安裝測試。
