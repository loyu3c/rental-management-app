# 0.23 撤銷位置與歷史狀態統一

撤銷操作統一在所屬紀錄卡片右下，按鈕與內文同一橫列底部對齊，移除原額外10dp上距，維持至少48dp觸控高度與文字可換行。多操作使用右側按鈕欄。涵蓋記帳支出／轉帳、支出報表、帳戶流水、押金、收款、月帳單項目與抄表。月帳單撤銷仍需展開內容才顯示，按項目標示租金／水電。

仍保留於資料中的已撤銷支出、轉帳、押金及抄表：灰底、灰字、文字刪除線，非粗體，並以不含刪除線的已撤銷狀態標示，不能再次撤銷；歷史電表照片仍可查看。狀態不只靠顏色區分。

本批僅調整顯示，保留原帳務計算與撤銷規則：帳戶流水及有效報表仍排除已撤銷，租金收款／錯誤未收款帳單原本移除資料的撤銷流程不改為新的歷史格式。既有記錄不改寫。

驗收：全面搜尋確認無卡片外的撤銷action入口；既有Android單元測試、Release編譯、lint、Google契約測試。手機窄螢幕／大字體、底部對齊、卡片狀態與即時更新待實機驗證。
