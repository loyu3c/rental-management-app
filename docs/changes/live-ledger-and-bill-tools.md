# 0.7.0：移除年繳開單、數字分組與即時更新

## 最新需求與範圍

使用者要求拿掉「建立年繳租金」，需先算好水電再出單；金額千位加逗號，建立或變動後頁面直接更新；再加入相關功能，整批完成才提供APK。

- 完全移除年繳開單按鈕與方法。仍從「建立當月帳單」確認租金、水費、電表與合計後一次保存。自行繳水電的租約仍只開租金。
- 舊年繳帳單、收款分配與租約繳款週期保留，不刪除歷史，不自動取消預收。租约仍可記錄年繳週期，但沒有批量開立租金單的操作。
- 金額、差額、銀行餘額、預覽、複製明細與數字輸入使用千位逗號，例如9,550；格式化只影響文字，存檔仍為整數。日期與房號R1401不改成逗號數字。
- 保存成功後更新開著的租約帳單、帳戶總覽、帳戶流水／對帳、舊收款對應清單與支出報表，讀取最新保存資料，不需重開。父層對話框重繪時盡量保留捲動位置；關閉即解除更新註冊。
- 收租入口新增全部／有未繳（含未到期）／已開帳單全清／未開單篩選。未開帳單不能誤列已繳清。
- 每月新增「複製繳費明細」，內容只包含此租客、房號、月份、租金、水費、電費、讀數、應繳日期、總額、已付與未付；缺少租金或應代收水電時阻止複製。使用者自行貼到LINE，App不自動傳訊。

## 資料與相容

v3備份格式不變；不重写歷史帳單與收款。數字輸入解析去除显示逗號後才驗證金額；顯示金額解析遇長串備註不崩潰，重複格式化亦不破壞已分組金額。applicationId、固定簽署不變，versionCode=9。
