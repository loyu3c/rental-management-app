# 暖色帳本與不動產分類

2026-10-03，使用者已選定暖色帳本，要求房屋改為不動產，支援停車場的土地出租。此變更補充既有規格，衝突時以本文件為準。

## 介面

採暖色帳本方向：暖色底、棕色重點、以流水與資金餘額為主，清楚區分收入、支出與轉帳。底部入口：首頁、收租、記帳、不動產、報表。

示意數字不得當正式帳，未建檔顯示尚未設定。完整風格尚待套入Android版，不宣稱已更新APK。

## 不動產模型

Property取代僅限Building的上層概念：房東ID、名称、類型（建築物/土地）、位置、管理模式、預設收款帳戶。房號改為依類型顯示的單位編號，不要求土地填棟別或房號。

出租單位與用途分開：土地可整筆或依實際範圍出租，用途可為停車場；不能把停車用途等同出租單一車格。

- 土地租給停車場經營者：建立土地租約，收土地租金，不自動建立每個車位的租約。
- 自己出租車格：建立停車格出租單位與獨立租約，不綁定住宅房客。
- 若同一土地存在多種出租範圍，按實際涵蓋範圍檢查租期衝突；不能假設用途不同就可重疊出租。
- 無電表或不代收水電的土地/車格，不要求填抄表資料。

費用分攤上層從棟別擴為不動產ID；A/B/C仍可用棟名顯示。土地租金、車格租金、住宅租金分列，總收入加總一次；所有租約均支持押金設定、收款、結算及歷史保存。

## 驗收

1. 導覽顯示不動產，建檔可選建築物或土地。
2. 土地租作停車場，無房號/水電也能建立獨立租約。
3. 土地租約不自動產生車格收入；車格承租人不要求住宅租約。
4. A/B/C既有資料保留不變；支出可分攤到土地與建築物，合計等於付款。
5. 無正式資料時不顯示假餘額，未完成服務不得顯示成功。
