# 0.24 修改帳戶名稱

帳戶流水頁新增修改帳戶名稱，可修正銀行／現金代稱。名稱不可空白，不得與其他帳戶同名（忽略大小寫）。保存前使用既有帳務驗證；僅改accounts.name，不改id、帳戶類型、期初、所屬不動產、收付關聯及交易分配。來源的歷史名稱快照不改寫；顯示有accountId的收款使用目前名稱，舊未對應收款保留原文字。

保存後帳戶清單、流水標題及已開啟明細更新；對帳日期與捲動保留。原修正期初入口保留，修改名稱不需修改期初或重新建帳戶。

驗收：既有Android帳務單元測試、Release編譯、lint及同步契約測試。實機驗證名稱更正、空白／同名拒絕、清單／流水／收款名稱更新及餘額、分配不變。
