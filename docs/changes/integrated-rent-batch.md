# 0.5.0 整合測試版：分層不動產與收租

## 規格與範圍

解決大量單位造成整頁操作按鈕，以及每個小變更都要下載測試的問題。暖色介面保留，將相關功能合併為一個測試版。

- 不動產清單 → 搜尋／篩選出租單位 → 單位與歷史租約。代號採數字自然排序，C2 排在 C10 前。按返回鍵逐層返回。
- 修改不動產名稱、單位代號、租約；已有帳單或收款時鎖定租期、租金、押金及繳款週期；姓名、Gmail、水電設定可修改，水電只套用新開立帳單，保留舊帳單快照。換人必須建立另一份租約。
- 出租狀態按台北日期與租期判定；未建租約不等同已確認空置。整棟租約會在相關單位顯示。
- 月租金帳單與當月水電帳單分別建立。電費=(本期-上期)*租約電價，月水費未設定時不能開水電單；自行繳水電的租約不能開水電單。此版輸入整數度數、整數新臺幣。
- 首末月不自動按天折算，使用者填實際月租金。年繳從指定月份開最多12張租金帳單，遇租約到期停止；折扣或不完整月份請改用逐月實際金額。租金帳單每月顯示約定應繳日，不另行產生年度催款單。
- 一筆實際銀行匯款記錄日期、帳戶代稱、總金額、備註，依月份先後、當月租金先於水電分配；確認前顯示清單。部分付款留下未付，超額留在原收款的未分配金額，可於開立帳單後再分配。
- 年繳只記一次實際收款。押金不計入租金收款，本版仍只有約定押金欄位，尚未實作押金收付。
- 同一租約、日期、帳戶、金額禁止重複收款登錄；銀行確有兩筆相同款項時需先核對，本版沒有銀行自動匯入。
- 可撤銷未收款錯誤帳單，及錯誤收款登錄（一起移除分配）；此功能不能代替實際退款，尚未提供正式稽核歷程。
- 首頁顯示已開帳單、本月實際收款、全部未付與已逾期。未建帳單的金額不會估算成欠款。銀行餘額、費用、房貸、零用金仍未實作。

Google、拍照、語音及真正支出記帳仍未啟用。請以測試資料驗證此版，不代表完整正式帳務系統。

## 資料與升級

保留 applicationId 與固定簽署設定，versionCode=5。SharedPreferences 原 properties/units/leases 保留；新增 invoices/receipts。帳單快照不因代號／姓名修改而變動。金融計算使用整數且有範圍與溢位檢查。

備份格式 rental-catalog v2 包含全部五類資料；舊 v1 可還原但帳單與收款會清空，確認訊息明確說明。還原先檢查關聯、代號重複、租约重疊、金額、跨租約分配與超額收款，再以單一 commit 原子替換。不得將備份上傳到程式庫。

## 驗收案例

1. Given 多個單位，When 搜尋 R1401 或篩選出租中，Then 只顯示符合的單位，操作集中在明細內。
2. Given 租金10000、水費250、用電60度*5，When 收10300，Then 租金付清、水電尚欠250，實際收入只有10300。
3. Given 12張每月10000租金單，When 收年繳120000，Then 12張付清、收款紀錄只有1筆。
4. Given 舊租客帳單與新租客租約，When 新租客繳款，Then 不抵付舊租客帳單。
5. Given 水費未設定、讀數倒退、重複月租帳單，When 開立，Then 阻止保存。
6. Given 收款超額尚未分配，When 後續建立帳單並分配，Then 原收款總额與筆數保持不變。
7. Given 備份有跨租約分配或超額分配，When 還原，Then 驗證失敗、不替換手機資料。
