# 出租單位代號

2026-10-03 使用者指定例子：車位 C1、房號 R1401。

- 出租單位具有穩定內部ID與可編輯顯示代號；租約與歷史帳務關聯ID，不以代號作主鍵。
- 車位例 C1；房間例 R1401。不自動解讀1401為樓層/地址，亦不限制只有此格式。
- 同一不動產內代號不得重複；不同不動產可有相同代號，選單與帳單須搭配不動產名稱以避免混淆。
- 代號與類型分開保存：類型房間、車格、土地出租範圍等由明確設定決定，不只靠字母判斷。
- 土地代號由管理者自行設定，未指定格式。
- 編輯代號不改變內部ID、租客、租約或帳務歸屬；已開立帳單保存當時的代號快照以供追溯。

驗收：可建立C1車位與R1401房間；跨不動產同代號可區別；同不動產重複代號阻止；改名後舊帳仍能追溯。
