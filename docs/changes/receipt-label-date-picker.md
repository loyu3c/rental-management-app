# 0.6.1：收到租金與點選日期

## 規格

使用者回饋「登錄一筆合併匯款」容易誤解，且手動輸入日期格式會出錯。按鈕改為「＋ 收到租金」，收款表單同名；金額標註「實際收到金額（含一起繳的水電費）」，保留原合併收款與分配規則。

日期欄位改為點選開啟Android原生日曆，涵蓋收款、租約起迄、帳戶起算、支出、轉帳、查詢／對帳及期初修正。禁止手動輸入與鍵盤，選定才更新文字；取消不更動。租約起迄仍必須由使用者選擇，不自行假設租期。

帳單月份、年繳開始月份、支出報表月份改為年／月選擇器，無需手打；可選1900到2200年。已有帳務鎖定的租約日期仍不可點選變更。到期早於起租、對帳早於起算等業務檢查仍保留。

## 相容與驗收

只改文案與輸入方式，不改日期ISO儲存格式、不遷移或重寫帳單／收款／餘額。v3備份、applicationId及固定簽署沿用，versionCode=8。

- [ ] 手機確認點擊跳出日曆、不跳文字鍵盤、取消保持原值；日期選擇後可正常保存。
