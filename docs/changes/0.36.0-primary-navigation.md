# 0.36.0-preview：第二層頁籤與集中設定

## 範圍

依 UI 架構規範整理主要入口，不改帳務模型、備份版本或 Google 分享權限。本版包含使用者回報的頁首間距修正：返回與標題左右留 12dp、租約代號與姓名分行，所有共用頁首一起套用。

| 底部入口 | 第二層 | 主要操作 |
|---|---|---|
| 首頁 | 無 | 摘要、待辦、到期提醒 |
| 收租 | 應收帳務／收款紀錄 | 同一租約詳情、同一收款查詢實作 |
| 記帳 | 支出／轉帳／帳戶 | 列表右上新增、語音、單筆更多；帳戶流水與對帳 |
| 不動產 | 物件／房東 | 右上新增、物件與單位更多操作、房東資料與歸屬 |
| 報表 | 房東／租客／管理總覽 | 專屬預覽與連結；統計入口回原詳情操作 |

設定固定由主要頁面右上角齒輪進入：Google 設定與測試、完整備份／還原、支出類別、舊收款帳戶對應。Google 設定使用共用全頁表單，保留儲存及測試連線原流程。

## 行為與相容

- 第二層頁籤固定於主要頁首，不隨列表捲動。頁籤選擇在切換底部入口時保留，Activity 重建時還原頁籤索引。
- 不動產深層頁改為左上返回，返回實際上一層；房東頁籤不誤用仍保留的物件路徑。
- 支出與轉帳分開顯示、分開合計，包括已撤銷查詢；月份／搜尋／有效狀態在兩頁共用並明示目前條件。
- 收款紀錄在頁籤內直接查詢；沿用既有 PaymentHistory，保留本次使用階段的月份、類型與搜尋。
- 房東管理及帳戶清單共用原本 renderer，不建立第二套保存流程。
- 保留語音記帳入口；語音草稿仍可選支出、收款或轉帳，確認前不入帳。
- 本機保存後仍刷新主要頁面；Google 報表維持手動更新。
