# 0.34.0-preview

- Rename the owner report, add multiple owners and explicit property/account ownership. Existing assets stay unassigned until reviewed; legacy transactions remain intact. Catalog schema 12 includes owners and report sharing metadata. Import marks sharing status unconfirmed.
- Add allowlisted owner snapshots with only their properties, anonymized unit billing, occupancy/vacancy/disabled counts, lease dates and account summaries. Mixed-ownership accounts withhold balances rather than exposing unrelated funds. The all-owner report remains local administrator-only.
- Add tenant-only projections for lease terms, deposits, invoices with rent/water/electricity breakdowns, receipt allocations and settlement top-ups. PDF contracts are sent only to the matching tenant report.
- Add version-2 Google service with per-subject fixed spreadsheet files, private PDFs, explicit reader permissions, verified ACLs, no notification emails and remote revoke for both file types. The selected month replaces the entire owner snapshot. v1 admin synchronization remains backward compatible but is not used for new recipient sharing.
- Add report link management, last confirmed state, copy/open, uncertain failure states, guards before changing shared recipients/ownership, and explicit on-device confirmation before uploading/sharing. Deployment must include Shared.gs, the updated manifest, Drive/Sheets authorization and a new deployment version. No real Google files are deployed or shared by compiling this APK.
- Add JVM projection/ownership tests and Node sharing/permission tests. See google-sync/SHARING_SETUP.md for deployment and operating limits.
