# 0.3.0 目錄修改與租約建檔

範圍：修改不動產名稱、出租單位代號；新增與查看單一單位租約。資料ID不變，不刪除歷史。

租約保存租客姓名、Gmail、開始/結束日期、月租金、應繳日、月繳/年繳、約定押金、代收水電模式及每月固定水費（可留空待設定）。電費單價預設5元。押金約定不代表已收到。

日期格式YYYY-MM-DD，結束不得早於開始；日期包含起迄日，重疊時拒絕新增。同不動產整棟與其他單位租約互斥；不同獨立單位可同期出租。此版不提供多單位或部分土地範圍交疊模型。

验收：更名保留ID；重複代號拒絕；租約金額/日期/Gmail檢查；同單位重疊拒絕；整棟衝突拒絕；水費未知保留待設定；重啟讀回。

未包含：收款、押金實收、帳單、退租結算、租約修改、備份及同步。僅用測試資料；實機驗收待使用者測試，CI只確認编譯/lint。
