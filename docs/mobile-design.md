# 手機畫面與資料結構設計草案

依 docs/requirements.md；2026-10-03。此文件為設計，尚非已完成的功能。

> 2026-10-17 更新：本文件保留早期業務與模型草案。畫面入口、頁籤、按鈕與附件互動以 [UI 與功能架構開發規範](ui-architecture-guidelines.md) 為準；以下舊版畫面配置不是新功能的實作依據。

## 手機入口

底部導覽：首頁、收租、記帳、房屋、報表。設定從首頁進入。

### 首頁

- 月份選擇；本期應收、已分配收款、尚欠，另列逾期欠款。年繳按帳單分配計算，不混同當月銀行現金收入。
- 各銀行帳面餘額與最後對帳日期、共用現金餘額、待退押金總額；不把餘額宣稱為可自由使用資金。
- 本月各棟支出與合計，房貸總扣款單獨可辨識。
- 快速操作：抄表、收款、支出、語音記帳。
- 待辦：未抄表、水費待設定、待核對收款、待同步。

### 收租

- 依月份與棟別查房號、租客、租金、水費、電費、應收、已收及欠款。
- 抄表：選房間，顯示上次讀數/日期，拍照或選相簿，輸入本次讀數，預覽度數與電費，確認。
- 讀數下降時阻止一般結帳，要求記錄電表更換/歸零原因與新基準，不直接算負電費。
- 帳單：水費未設定時保持草稿；自行繳水電租約不加代收項目。
- 收款：選租約、金額、銀行帳戶、實際入帳日期；勾選帳單項目與分配金額，確認存摺核對後入帳。
- 部分款列欠款，溢付款列未分配款；年繳涵蓋月份須預覽確認，水電仍逐月開帳。

### 記帳

- 分頁：支出、資金移動、押金、流水。
- 支出填日期、類別、描述、付款帳戶、金額；棟別分攤逐列填入，顯示尚未分攤金額。提供房貸與電梯保養類別。
- 提款、存回、帳戶轉帳：來源、目的、金額、日期，一次確認；不列費用。
- 押金：收取、退還、扣抵。扣抵關聯帳單或退租結算，不新增虛構銀行入帳；不得重複結算同筆欠款。
- 語音：按麥克風、轉寫、顯示類型/日期/金額/房號或棟別/帳戶/分攤草稿，補缺漏、確認。取消不改帳。
- 保存後分別顯示本機保存結果與報表同步狀態。

### 房屋

- 棟別→出租單位→租約。整棟租約关联該棟所有覆蓋單位，驗證日期重疊。
- 租約保存姓名、Gmail、起迄、月租、繳租日、月繳/年繳、指定帳戶、水電模式、單價與固定水費。
- 起租時設電表基準。續租保留舊租約與帳務，不覆寫歷史。
- 押金明細與照片歷史；租客Gmail異動須重新確認報表授權並撤除舊權限。

### 報表與設定

- 總览、各棟收支、銀行/現金流水、租約欠款、押金。
- 對帳：選帳戶與存摺截至日期，輸入實際餘額，與相同日期帳面比較；標記已核對交易，不強行填平。
- 歷史補登：明示起算日前/後，資料補登中的月份標記。
- Google：爸爸報表與每租約報表連結、最後成功時間、失敗原因、重試。
- 初始設定：起算日、銀行/現金餘額、期初欠款、押金、預收款；備份/還原功能需在正式記帳前完成。

## 資料結構

金額採整數最小貨幣單位，禁止二進位浮點累加；電表讀數與單價採十進位，帳單明示捨入規則。業務日期使用Asia/Taipei，事件時間保存UTC。

| 資料 | 核心內容 |
|---|---|
| Owner | 房東ID、顯示姓名、報表Gmail |
| Building / Unit | 房東ID、棟別、房號、是否可出租 |
| Account | 房東ID、名稱、銀行/現金、期初日期與金額 |
| Tenant / Lease / LeaseUnit | 租客、Gmail、租約、涵蓋單位、收費設定 |
| Meter / Reading / Attachment | 電表、讀數、日期、照片位置與新基準事件 |
| Invoice / InvoiceLine | 租約、帳期、應繳日、租金/水電項目、計價快照、應收 |
| Transaction / LedgerEntry | 穩定交易ID、類型、日期、帳戶增加/減少、確認/撤銷狀態 |
| ReceiptAllocation | 收款對帳單項目分配，不自行增加銀行餘額 |
| ExpenseAllocation | 支出對棟別分攤，不重複扣款 |
| DepositEvent | 租約押金收退扣抵、關聯交易或期初資料 |
| OpeningPosition | 起算時欠款、預收與押金；標明歷史資料已包含部分 |
| Reconciliation | 帳戶、截至日期、實際/帳面餘額、差額、核對時間 |
| VoiceDraft | 原轉寫、待補欄位、候選資料、確認後交易ID |
| ReportTarget / SyncJob | 爸爸或租約目標、檔案ID、版本、重試、最後成功時間 |
| AuditEvent | 修改前後、理由、時間；已入帳更正須可追蹤 |

## 必須維持的規則

- 銀行/現金餘額只從期初與有效流水推導。帳單、分攤與同步本身不增減資金。
- 付款分配不能超過該筆收款可分配餘額或帳單尚欠。押金與租金不能默認互抵。
- 相同房東的轉帳两側原子保存；跨房東移動不得套用此簡單規則。
- 已確認金額、讀數与帳單更正留紀錄；撤銷後重新計算餘額與欠款。
- 起算前歷史標記不影響期初後資金；期初押金/欠款也不可重複計入。
- 保存交易與待同步任務一起提交；穩定ID與版本防止重試重複。未連網可本機記帳，報表明示尚未更新。
- 爸爸報表含其三棟；租客報表僅該租約。電話不輸出。照片不做額外租客隔離，但正式帳務不可公開。

## 技術實作前仍需落實

- Android工具鏈版本、Google登入及授權、雲端備份和照片位置、語音服務方案需核對官方文件。
- 優先建立可安裝且可更新的APK骨架，再逐步完成業務功能；示範資料與正式資料明顯區隔。
- GitHub Actions提供建置與測試產物；正式簽署金鑰由專案Secrets保存，不能每次重建造成無法覆蓋安裝。
- Google同步、語音與備份未完成前明確標示，不以假成功提示代替服務。
